# 60-Second Capture Checklist

The next review needs 60 seconds of unedited gameplay from the vertical slice,
captured on real PC hardware. No trailer polish, no cuts.

## What must be visible in the 60 seconds

- [ ] Main menu → PLAY MATCH, no dead ends
- [ ] Skating with the puck (gamepad, left stick)
- [ ] A pass to a teammate
- [ ] A shot on goal (aimed at a corner) and a save or a goal
- [ ] A check that flattens a zombie for 2 seconds and knocks the puck loose
- [ ] A goal, the score updating, and play resetting to the faceoff
- [ ] The period clock running and the live FPS readout visible (target: 60)
- [ ] The final whistle or the match-end result screen, if the capture runs that long

## Recording setup

- Record at 1280×720, 60 fps (OBS or equivalent), game audio on, no commentary.
- Play on the Low preset on the minimum-spec machine (i3-6100 / GTX 750 Ti) if one is available; otherwise record the machine's specs alongside the file.
- Name the file `zhl-60s-capture-YYYY-MM-DD.mp4` and attach it to the next review — do not check the video into the repo.
